# Sidebar agent roster fixes

Audit of the hook → `WorkstreamAgentStateTracker` → `MainAgentPortrait` / `WorkstreamAgentRosterView` pipeline (2026-10-23). Findings are also listed in `TODO.md` under Bugs.

## Root causes

1. **Ring bounces off the portrait after a space switch.** `MainAgentPortrait.swift` pulses with `.animation(.repeatForever, value: isPulsing)` on the ring Circle (same on `RosterAvatar`, `WorkstreamAgentRosterView.swift`). The implicit animation also captures the ring's layout position when the List re-measures rows in the same update as the appear-time `isPulsing` flip. Side effects of the same design: `onChange(of: pulseDuration)` starts two overlapping animations; re-appearance with `isPulsing` already true gets no pulse; the shadow never pulses.
2. **Orphaned subagent cards.** Runs leave the roster only on `SubagentStop` / OpenCode idle. Lost stops happen (Claude `Stop` hook does not fire on user interrupt; `ff-hook` curl `--max-time 1` drops silently; in-process teammates emit tool hooks with no SubagentStart/Stop). Main `Stop` with any child removes only main and forces row `.working` with no exit path.
3. **Subagent shows the Claude portrait.** `upsert` defaults `name ?? "Claude"` for any id; receiver ignores `agent_type` on PreToolUse/PostToolUse though Claude Code sends it inside subagents; `describedAgents` is never cleared so a recreated run gets no name.
4. **Stalled only recovers on PreToolUse.** `agentToolDone` refreshes `lastEventAt` but leaves run and row `.stalled`.
5. **`isWaitingForUser` never cleared on PostToolUse.** Suppresses stall detection workstream-wide (`anyWaiting`); a subagent's answered question keeps the row at "Waiting for approval".
6. **Interrupted turn leaves the main run.** Row shows Stalled while idle; next prompt reuses the old `startedAt`.
7. **Notification classified by message substring.** Claude Code sends `notification_type` (`permission_prompt`, `idle_prompt`, `agent_needs_input`, …).

Known limitation, not addressed: two Claude sessions in one worktree share the single `main` run.

After the existing stall/row logic, if the roster for that workstream is now empty and the row is `.working` or `.stalled`, set the row to `.idle` when `currentSelection == wsID`, else `.needsAttention(.justFinished)` (same rule the main-idle path uses). ## Task 3: Views — clock-driven pulse, no implicit animation

Files: `Sources/Views/MainAgentPortrait.swift`, `Sources/Views/WorkstreamAgentRosterView.swift`, `TODO.md`.

Context: both views pulse a ring with `.animation(.easeInOut(duration: d).repeatForever(autoreverses: true), value: isPulsing)` driven by `@State isPulsing` flipped in `onAppear`/`onChange`. When the sidebar `List` re-measures rows (space switch) in the same update as the flip, the implicit animation also animates the ring's layout position and the ring bounces forever, offset from the portrait. Fix: derive the ring opacity from the clock instead, with no implicit animation and no state.

Changes:
1. In `MainAgentPortrait.swift` add (same file, no new file):
   ```swift
   /// Ring whose opacity follows the clock; nil period = static ring. No implicit
   /// animation, so a layout move during a List re-measure can never be captured
   /// into a repeating animation (the ring used to bounce after a space switch).
   struct PulsingRing: View {
       let color: Color
       var lineWidth: CGFloat = 1.5
       /// Full bright→dim→bright cycle length; nil draws a static ring.
       var period: TimeInterval?

       var body: some View {
           TimelineView(.animation(minimumInterval: 1 / 30, paused: period == nil)) { context in
               Circle().strokeBorder(color.opacity(opacity(at: context.date)), lineWidth: lineWidth)
           }
       }

       private func opacity(at date: Date) -> Double {
           guard let period else { return 1 }
           let phase = date.timeIntervalSinceReferenceDate.truncatingRemainder(dividingBy: period) / period
           return 0.675 + 0.325 * cos(2 * .pi * phase)   // 1.0 → 0.35 → 1.0
       }
   }
   ```
2. `MainAgentPortrait`: delete `@State isPulsing`, `.onAppear`, `.onChange(of: pulseDuration)`, and every `.animation(…)` modifier. `ringedPortrait` uses `PulsingRing(color:lineWidth:period:)` with period `1.6` for `.working`, `2.8` for `.stalled`, `nil` otherwise (the old 0.8/1.4 one-way durations doubled). Shadow becomes static `.blue.opacity(0.35)`.
3. `RosterAvatar` in `WorkstreamAgentRosterView.swift`: delete `@State isPulsing`, `.onChange(of: state)`, `.onAppear`, `.animation(…)`; ring = `PulsingRing(color: ringColor, period: state == .working ? 1.6 : nil)`. Keep the 30×30 frame and the portrait.
4. `TODO.md`: remove the seven Bugs entries this plan fixes (ring bounce; orphaned subagent cards; subagent gets "Claude" name; stalled only recovers on PreToolUse; `isWaitingForUser` not cleared on PostToolUse; interrupted turn leaves main run; Notification parsed by substring).
